# 중국어 폰트 모음

요청 이미지의 추천 조합에 맞춘 중국어 폰트입니다. 기존 한국어 폰트 파일은 변경하지 않습니다.

| 용도 | 폰트 | 보관 내용 |
|---|---|---|
| 큰 제목 | 阿里巴巴普惠体 Alibaba PuHuiTi | 아래 공식 다운로드 링크만 제공. 공개 재배포 권한이 명확하지 않아 바이너리 제외 |
| 개성 있는 제목 | 得意黑 Smiley Sans v2.0.1 | SmileySans-Oblique.ttf, 단일 기울임 스타일 |
| 본문·설명 | 思源黑体 Source Han Sans SC 2.005R | OTF 7굵기: ExtraLight, Light, Normal, Regular, Medium, Bold, Heavy |
| 감사 문구 | 霞鹜文楷 LXGW WenKai v1.522 | Light, Regular, Medium TTF 원본을 각각 ZIP으로 보관 |

## 먼저 사용해 볼 파일

- 개성 있는 제목: [SmileySans-Oblique.ttf](SmileySans-Oblique.ttf)
- 본문: [SourceHanSansSC-Regular.otf](SourceHanSansSC-Regular.otf)
- 감사 문구: [LXGWWenKai-Regular.zip](LXGWWenKai-Regular.zip)
- 알리바바 큰 제목: 공식 2.0 배포본의 **AlibabaPuHuiTi-2-115-Black.ttf**

TTF/OTF는 내려받아 설치하세요. LXGW WenKai는 웹 업로드 크기 제한 때문에 ZIP으로 압축했으며, 압축을 풀면 TTF와 OFL.txt가 나옵니다. 폰트 데이터는 변환하거나 수정하지 않았습니다.

- 무료 상업적 사용 허용과 공개 재배포 허용은 다릅니다. 공식 고지에서 공개 저장소 재배포 허용을 확인하지 못했으므로 이 저장소에는 알리바바 폰트 파일을 올리지 않습니다. 공식 출처에서 직접 다운로드하고 동봉 고지를 확인하세요.

## 라이선스 및 출처 기록

알리바바를 제외한 위 3종은 SIL Open Font License 1.1에 따라 원문 저작권·라이선스 고지를 함께 보관합니다. 폰트 단독 판매 및 수정본의 예약명 사용 등에는 제한이 있으므로 각 원문을 확인하세요. 이 안내는 기존 저장소의 한국어 폰트에 새 라이선스를 부여하지 않습니다.

각 *-manifest.json에는 공식 버전, 다운로드 URL, 원본 파일 크기를 기록했습니다. SHA256SUMS.txt는 저장소 배포 파일의 무결성 확인용입니다.
